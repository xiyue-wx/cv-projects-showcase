# Computer Vision Projects Showcase
## 1. Robust 3D Point Cloud Registration (GeoCORNet)
- **Project Overview**: Developed a deep learning framework (GeoCORNet) for robust 2D/3D image and point cloud registration in low-overlap, noisy, and deformed scenarios.
- **My Contribution**: Designed geometric constraint enhancement, bidirectional cross-attention, and displacement correction modules to solve core challenges of sparse, low-overlap, and high-noise 3D data alignment.
- **Publication**: First-author paper published in *Sensors* (SCI, IF=3.8), DOI: 10.3390/s25144332
- **Tech Stack**: PyTorch, Open3D, Python, NumPy, C++

## 2. Tea-Picking Robot Visual Perception System
- **Project Overview**: Independently designed and optimized the young tea leaf detection algorithm for agricultural picking robots, verified deep learning model deployment in complex real-world environments.
- **My Contribution**: Proposed a recognition network integrating spatial features and point-wise correction, improved target recognition accuracy from 72% to 91% and reduced inference latency by 25% in field tests.
- **Tech Stack**: PyTorch, OpenCV, Python, C++
